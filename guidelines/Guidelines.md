# Parapente La Unión - Design Guidelines

## Aesthetic Stance
**Adventure Modern** — Clean, energetic design for extreme sports. Bold typography, dynamic gradients, and generous whitespace create a professional yet thrilling atmosphere. Purple-based palette evokes sky, adventure, and premium experience.

## Typography

### Display
- **Primary**: Work Sans (Bold/SemiBold) for headings
- **Purpose**: Strong, modern sans-serif that conveys confidence and energy

### Body  
- **Primary**: Inter for body text and UI elements
- **Purpose**: Clean, highly readable for all content

## Color Palette

### Primary Purple Gradient
- Deep Purple: `#6B46C1` (primary brand color)
- Bright Purple: `#9333EA` (accents, highlights)
- Light Purple: `#C084FC` (hover states, secondary elements)

### Supporting Colors
- Sky Blue: `#3B82F6` (call-to-action elements)
- Dark Background: `#0F0A1E` (deep purple-black for contrast)
- Light Background: `#F9FAFB` (clean sections)
- White: `#FFFFFF` (content areas)

### Text
- Primary: `#1F2937` (dark gray for body text)
- Secondary: `#6B7280` (muted text)
- On Dark: `#F9FAFB` (text over dark backgrounds)

## Visual Treatment

### Layout
- Generous whitespace and breathing room
- Asymmetric compositions where appropriate
- Max content width: 1280px
- Section padding: 80-120px vertical

### Imagery
- Full-bleed hero images with gradient overlays
- High-quality paragliding photos
- Purple-tinted overlays for brand cohesion

### Interactive Elements
- Smooth transitions (200-300ms)
- Hover effects on all interactive elements
- Purple glow effects on focus states

### Components
- Rounded corners: 12px (cards), 8px (buttons), 24px (large cards)
- Shadows: Subtle elevation with purple tint
- Buttons: Bold, clear CTAs with gradient backgrounds

## Responsive Behavior
- Mobile-first approach
- Breakpoint: 768px (tablet), 1024px (desktop)
- Stack columns on mobile, grid layouts on desktop
- Scale typography for smaller screens
